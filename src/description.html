Опис предметного середовища та бізнес-логіки

1. Опис предметного середовища

Предметною галуззю є розробка WEB-застосунку для гравців у настільні рольові ігри. Застосунок працює як цифровий аркуш персонажа (Character Sheet) та довідник. Він дозволяє гравцям створювати нових героїв, обирати їхні класи, генерувати характеристики, керувати інвентарем та зберігати список доступних заклинань.

2. Опис бізнес-логіки (сценарій використання)

  1. Користувач заходить на головну сторінку та переглядає доступні інструменти.
  2. Користувач заповнює HTML-форму для створення персонажа (вказує ім'я, расу, рівень).
  3. Система відображає базові характеристики та дозволяє розподілити спорядження.
  4. Користувач переглядає таблицю здібностей, де відображається його зброя, броня та магічна шкода.

3. Функціональні вимоги

  • Форми для введення текстових та числових даних персонажа.
  • Виведення даних про заклинання, зброю та характеристики у вигляді структурованих таблиць.
  • Наявність списків для відображення класів.
  • Відображення зображення (портрета) персонажа.

4. Нефункціональні вимоги

  • Інтуїтивно зрозумілий інтерфейс (UI).
  • Коректне відображення сторінок у сучасних браузерах (Chrome, Firefox).

⬅ Повернутися на головну сторінку застосунку
